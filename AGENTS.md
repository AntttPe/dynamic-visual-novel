# Instrukcje dla agentów AI

Ten plik jest dla agentów innych niż Claude Code (Codex, Cursor, Copilot itp.).

1. Przeczytaj `CLAUDE.md`: opis projektu, architektura i zasady pracy. Obowiązują wszystkich agentów.
2. Przeczytaj `PROGRESS.md`: aktualny stan projektu, zadania w toku i dziennik zmian.
3. Przed pushem z większą zmianą zaktualizuj `PROGRESS.md` według zasad na jego początku.
